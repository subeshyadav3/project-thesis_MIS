\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

The Project/Thesis Management System (TPMS) is a web-based platform developed for the Department of Electronics and Computer Engineering (DOECE), Pulchowk Campus, Institute of Engineering, Tribhuvan University. The system digitalizes and automates the complete administrative and evaluative lifecycle of Bachelor Minor and Major projects and Master research theses across six academic programs, replacing existing manual, paper-based workflows with a centralized, role-aware digital ecosystem.

The platform enforces a five-role hierarchy comprising Maintainer, Coordinator, Supervisor, Student, and External Examiner, governed by Role-Based Access Control (RBAC) with strict program-scoped degree isolation. A Global Engagement Guard prevents students from enrolling in multiple active project groups simultaneously. An automated Conflict-of-Interest Filter ensures that project supervisors cannot concurrently serve as defense evaluators for their own supervised projects. The system implements the DOECE evaluation schemes for Minor projects (50 marks), Major projects (100 marks), and Master Theses (300 marks) through a dynamic rubric engine.

Key technical contributions include a Puppeteer headless browser pipeline that generates official A4 PDF grade sheets with automated number-to-words mark conversion, and a SheetJS-powered Excel bulk import pipeline with pre-commit anomaly detection. A program-scoped, tamper-evident audit trail ensures institutional accountability for all administrative and evaluative events.

The system is implemented using React 18 with Vite 5 on the frontend, Node.js with Express.js on the backend, and PostgreSQL 16 managed via Prisma 5 ORM. Evaluation through unit testing (36 tests, 100\% pass rate), integration testing, security testing, and User Acceptance Testing (satisfaction score 4.47 out of 5.0) confirmed functional completeness and operational readiness for intranet deployment at DOECE, Pulchowk Campus.

\noindent\textbf{Keywords:} \textit{Role-Based Access Control, Project Management, Evaluation Rubric Engine, PDF Generation, Node.js, React, PostgreSQL, Prisma ORM.}
