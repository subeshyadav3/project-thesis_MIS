The Project/Thesis Management System (TPMS) is a web-based platform developed for the Department of Electronics and Computer Engineering (DOECE), Pulchowk Campus, Institute of Engineering, Tribhuvan University. The system digitalizes and automates the complete administrative and evaluative lifecycle of Bachelor Minor and Major projects and Master research theses across six academic programs (BCT, BEI, MSCSK, MSICE, MSDSA, and MSNCS), replacing existing manual, paper-based workflows.

The platform enforces a five-role hierarchy (Maintainer, Coordinator, Supervisor, Student, and External Examiner: governed by Role-Based Access Control (RBAC) with strict program-scoped degree isolation. A Global Engagement Guard prevents students from enrolling in multiple active project groups simultaneously. An automated Conflict-of-Interest Filter ensures that assigned project supervisors cannot serve as defense evaluators for their own supervised students. The system implements the DOECE evaluation schemes for Minor projects (50 marks), Major projects (100 marks), and Master Theses (300 marks) through a dynamic rubric engine.

Key technical contributions include a server-side Puppeteer headless browser pipeline that generates official A4 PDF grade sheets with automated number-to-words mark conversion, and a SheetJS-powered Excel bulk import pipeline with pre-commit anomaly detection for large-scale student onboarding. A program-scoped, tamper-evident audit trail provides institutional accountability.

The system is implemented using React 18 with Vite 5 on the frontend, Node.js with Express.js on the backend, and PostgreSQL 16 managed via Prisma 5 ORM. Evaluation through unit testing (36 tests, 100\% pass rate), integration testing, security testing, and User Acceptance Testing (average satisfaction score 4.47 out of 5.0) confirmed functional completeness and operational readiness.

\textbf{Keywords:} Academic Project Management, Role-Based Access Control, Evaluation Rubric Engine, PDF Grade Sheet Generation, Conflict-of-Interest Prevention, Node.js, React, PostgreSQL, Prisma ORM.
